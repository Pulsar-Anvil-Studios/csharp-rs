# Conditional `#nullable enable` Directive Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Emit `#nullable enable` in generated `.cs` files only when at least one optional field resolves to a C# reference type (e.g. `string?`, `List<int>?`), eliminating CS8669 compiler warnings without adding the directive to files that don't need it.

**Architecture:** At macro expansion time, we know which fields are optional (`is_optional: bool`) but not the resolved C# type name (determined at consumer compile time via `type_expr`). We emit a runtime check in the generated `csharp_definition()` that tests whether any optional field's resolved type is NOT a C# value type, and conditionally prepends `#nullable enable\n` after `// <auto-generated/>\n`.

**Tech Stack:** Rust proc-macro (`quote!`, `proc_macro2::TokenStream`), C# nullable reference types.

```rust
/// C# built-in value type keywords.
///
/// When an optional field resolves to one of these types, the `?` suffix
/// produces `Nullable<T>` and does **not** require `#nullable enable`.
/// Any other type (e.g. `string`, `List<int>`, user-defined records) is a
/// reference type whose `?` annotation only works under `#nullable enable`.
const CSHARP_VALUE_TYPES: &[&str] = &[
    "bool", "byte", "sbyte", "short", "ushort", "int", "uint", "long", "ulong", "float", "double",
    "decimal", "char",
];

/// Builds nullable-reference-type check expressions for a set of fields.
///
/// Returns one `TokenStream` per optional field. Each expression evaluates at
/// compile time (in the consumer crate) to `true` when the resolved C# type
/// is a reference type — meaning the file needs `#nullable enable`.
///
/// Non-optional fields are skipped because they never emit a `?` suffix.
pub(crate) fn nullable_ref_check_exprs(fields: &[CSharpField]) -> Vec<TokenStream> {
    let value_types: Vec<&str> = CSHARP_VALUE_TYPES.to_vec();

    fields
        .iter()
        .filter(|f| f.is_optional)
        .map(|f| {
            let type_expr = &f.type_expr;
            quote! {
                {
                    let csharp_type = #type_expr;
                    ![#(#value_types),*].contains(&csharp_type.as_str())
                }
            }
        })
        .collect()
}
```

```rust
fn build_file_scoped(
    using_directive: &str,
    namespace: &str,
    csharp_name: &str,
    field_exprs: &[TokenStream],
    nullable_checks: &[TokenStream],
) -> TokenStream {
    quote! {
        {
            let mut fields = String::new();
            let field_parts: Vec<String> = vec![#(#field_exprs),*];
            for (i, part) in field_parts.iter().enumerate() {
                if i > 0 {
                    fields.push('\n');
                }
                fields.push_str(part);
            }
            let nullable_checks: Vec<bool> = vec![#(#nullable_checks),*];
            let nullable_directive = if nullable_checks.iter().any(|&x| x) {
                "#nullable enable\n"
            } else {
                ""
            };
            format!(
                concat!(
                    "// <auto-generated/>\n",
                    "{nullable}",
                    "{using}\n",
                    "\n",
                    "namespace {ns};\n",
                    "\n",
                    "public sealed record {name}\n",
                    "{{\n",
                    "{fields}",
                    "}}\n",
                ),
                nullable = nullable_directive,
                using = #using_directive,
                ns = #namespace,
                name = #csharp_name,
                fields = fields,
            )
        }
    }
```

```rust
fn build_file_scoped(
    using_block: &str,
    namespace: &str,
    class_attrs: &str,
    csharp_name: &str,
    indent: &str,
    variant_exprs: &[TokenStream],
    converter_expr: Option<&TokenStream>,
    nullable_checks: &[TokenStream],
) -> TokenStream {
    let converter_append = build_converter_append(converter_expr);

    quote! {
        {
            let variant_parts: Vec<String> = vec![#(#variant_exprs),*];
            let variants_block = variant_parts.join("\n\n");
            let converter_block: String = #converter_append;

            let body = if variants_block.is_empty() && converter_block.is_empty() {
                String::from(";")
            } else {
                format!(
                    "\n{{\n{variants}{converter}\n}}",
                    variants = variants_block,
                    converter = converter_block,
                )
            };

            let nullable_checks: Vec<bool> = vec![#(#nullable_checks),*];
            let nullable_directive = if nullable_checks.iter().any(|&x| x) {
                "#nullable enable\n"
            } else {
                ""
            };

            format!(
                "// <auto-generated/>\n\
                 {nullable}\
                 {using}\n\
                 \n\
                 namespace {ns};\n\
                 \n\
                 {attrs}\n\
                 {indent}public abstract record {name}{body}\n",
                nullable = nullable_directive,
                using = #using_block,
                ns = #namespace,
                attrs = #class_attrs,
                indent = #indent,
                name = #csharp_name,
                body = body,
            )
        }
    }
}
```

### Notes

- **`simple_enum.rs` requires NO changes** — simple enums have no fields and never emit `?` on any type.
- **Newtype variants in tagged enums** are not checked — their `Value` property is always the unwrapped type (never `?`-suffixed). The derive generates `public required {type} Value { get; init; }` with no nullable marker. Only struct variant fields can be `Option<T>`.
- If `nullable_checks` is empty (no optional fields), `vec![].iter().any(|&x| x)` evaluates to `false`, and the directive is correctly omitted.
- The `CSHARP_VALUE_TYPES` list covers all C# built-in value types that map from Rust primitives via `impl_csharp_primitive!` in `lib.rs`. User-defined types are always records (reference types), and generic types (`List<T>`, `Dictionary<K,V>`, `HashSet<T>`) are also reference types.
