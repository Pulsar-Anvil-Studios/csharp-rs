# Plan : Implémentation Step 1 — derive CSharp pour structs named fields

**Status** : ✅ Terminé — 71 tests, 98.58% coverage

## Context

Le workspace `csharp-rs` est scaffoldé mais le derive macro est un stub. On implémente la première étape du roadmap : générer du C# (`sealed record`) depuis des Rust structs avec named fields, en respectant `serde(rename_all)`. C'est la fondation sur laquelle tout le reste sera construit.

## Décisions de design

- **C# 9.0 minimum**, version targeting configurable (9.0 défaut)
- **System.Text.Json + Newtonsoft.Json**, configurable (STJ défaut), 1 fichier par type
- **Attributs JSON toujours explicites** (même si redondant)
- **Namespace** : défaut via `[package.metadata.csharp]`, override via `#[csharp(namespace = "...")]`
- **Export** : `#[csharp(export)]` génère un `#[test]` caché (pattern ts-rs)
- **Config baked** au compile-time pour v0.1 (roadmap futur : Config runtime)
- **Output** : `sealed record` + `{ get; init; }` + block-scoped namespaces

## Scope Step 1

**Inclus :**
- Structs avec named fields uniquement
- Mapping types primitifs (String, bool, i32, f64, etc.)
- `Option<T>` → `T?`
- `Vec<T>` → `List<T>`, `HashMap<K,V>` → `Dictionary<K,V>`
- `serde(rename_all = "...")` sur le container
- `#[csharp(namespace = "...")]` et `#[csharp(export)]`
- Config depuis `[package.metadata.csharp]` dans Cargo.toml
- Attributs System.Text.Json et Newtonsoft.Json

**Exclu (étapes suivantes) :**
- `serde(rename)` / `skip` / `flatten` sur champs individuels
- Enums (simples ou taggés)
- Tuple structs, unit structs, newtype structs
- `untagged` / `tag` + `content`
- Config runtime
- Snapshot tests / compilation C# en CI

## Architecture

```
crates/csharp-rs-macros/src/
    lib.rs                  # entry point : #[proc_macro_derive(CSharp, attributes(csharp))]
    attr/
        mod.rs              # Inflection enum (8 conventions), trait Attr, helpers
        container.rs        # ContainerAttr : parse #[serde(rename_all)] + #[csharp(namespace, export, export_to)]
        field.rs            # FieldAttr : stub pour Step 1, préparé pour Step 3
    types/
        mod.rs              # dispatch Data::Struct → named::named_struct()
        named.rs            # génère DerivedCSharp depuis structs named fields
    codegen.rs              # DerivedCSharp → TokenStream (impl CSharp for T)
    config.rs               # lecture [package.metadata.csharp] depuis CARGO_MANIFEST_DIR

crates/csharp-rs/src/
    lib.rs                  # trait CSharp (existant) + impl CSharp pour primitifs + export_to (existant)
```

### IR intermédiaire : DerivedCSharp

```rust
struct DerivedCSharp {
    rust_ident: Ident,
    csharp_name: String,
    namespace: String,
    fields: Vec<CSharpField>,
    export: bool,
    export_to: Option<String>,
}

struct CSharpField {
    csharp_property_name: String,   // PascalCase
    json_name: String,              // après rename_all serde
    type_expr: TokenStream,         // <FieldType as CSharp>::csharp_name()
    is_optional: bool,
}
```

### Config Cargo.toml

```toml
[package.metadata.csharp]
namespace = "MyApp.Types"              # défaut: "Generated"
serializer = "system-text-json"        # ou "newtonsoft" (défaut: "system-text-json")
target = "9.0"                         # version C# (défaut: "9.0")
export-dir = "generated/csharp"        # défaut: "./csharp-bindings"
```

Lu au compile-time via `CARGO_MANIFEST_DIR` + parsing TOML basique (dépendance `toml` à ajouter).

## Étapes d'implémentation

### 1. Ajouter dépendance `toml` au workspace
- `Cargo.toml` racine : `toml = "0.9"` dans `[workspace.dependencies]`
- `crates/csharp-rs-macros/Cargo.toml` : `toml.workspace = true`

### 2. Implémenter le module `config.rs`
- Lire `CARGO_MANIFEST_DIR/Cargo.toml`
- Parser `[package.metadata.csharp]`
- Struct `CSharpConfig { namespace, serializer, target, export_dir }` avec défauts

### 3. Implémenter le module `attr/`
- `attr/mod.rs` : enum `Inflection` avec les 8 conventions + fn `apply(&self, name: &str) -> String`
- `attr/container.rs` : `ContainerAttr` parse `#[serde(rename_all)]`, `#[csharp(namespace, export, export_to)]`
- `attr/field.rs` : `FieldAttr` stub (struct vide, parsing minimal)

### 4. Implémenter le module `types/`
- `types/mod.rs` : dispatch `Data::Struct(DataStruct { fields: Named(...) })` → `named::named_struct()`
- `types/named.rs` : itère les champs, applique rename_all, construit `DerivedCSharp`

### 5. Implémenter `codegen.rs`
- `DerivedCSharp::into_token_stream()` → génère le TokenStream complet
- Gère le choix serializer (System.Text.Json vs Newtonsoft)
- Gère le namespace (config + override attribut)
- Si `export`, génère `#[test] fn export_type_name()`

### 6. Brancher dans `lib.rs`
- Remplacer le stub par le vrai pipeline : parse → attrs → types → codegen
- Gestion d'erreur via `syn::Error` / `compile_error!`

### 7. Implémenter les `impl CSharp` pour types primitifs
- Fichier : `crates/csharp-rs/src/lib.rs`
- Impls pour : `String`, `bool`, `i8`..`i128`, `u8`..`u128`, `f32`, `f64`
- Impls génériques : `Option<T>`, `Vec<T>`, `HashMap<K,V>`, `HashSet<T>`

### 8. Tests — 71 tests au total
- **20 unit tests** (`csharp-rs/src/lib.rs`) : primitives, generics, `export_to()`
- **14 tests d'intégration** (`csharp-rs/tests/derive_struct.rs`) : structs avec `#[derive(CSharp)]`
- **36 unit tests** (`csharp-rs-macros`) : attr parsing, config, codegen (STJ + Newtonsoft), types dispatch
- **1 doctest** (`csharp-rs/src/lib.rs`)
- `cargo clippy` passe clean avec les lints du workspace
